# Oktay İbiş

Mobile engineer. TypeScript, React Native, functional-first.
I lead mobile at Danske Bank. Here: open source and experiments.

## What I'm into

**Agentic development and the ADLC.** I care less about which model is
best and more about where AI-assisted development actually slows down:
context, review, verification, handoffs. Most of my experiments here
are about removing those bottlenecks.

**Open source.** I contribute to projects I use and build small
libraries for problems I keep hitting.
